## The game
Carry-and-build: fill your bag in the Blocks pit (stand in the yellow zone), ride the hoist (or walk the stairs) to the roof of the shared skyscraper and place blocks within Build Range of the build front. Every floor that fills grows the tower; when the last floor is done the building gets its crown, stands for a moment, sinks into the sand and a bigger one in a new shape starts (`BUILDINGS`). The elevator masts, stair tower and cranes always match the building's current height. Strength (bench press) sets bag capacity and bulks up the avatar; Speed (treadmill) sets walk speed. Gym pads unlock by buildings finished (premium pads with cash). Upgrades: Block Grab, Build Speed, Build Range, Elevator Speed. 30 ranks by total blocks placed (`RANKS`, +3% cash each). Crew (E next to a worker, +10% cash each), free gift timer, 7-day daily rewards, rotating world events, day/night cycle, leaderboard wall with podium statues. Robot Gear hall (`ROBOT_GEAR`, west of the leaderboard): wearable robot gear bought with cash (Jet Boots $25K to Titan Armor $50M), one piece worn at a time; each multiplies blocks placed per bag block and Build Speed and adds Walk Speed (HUD units) and capacity; transformers turn into their vehicle on G (the Jet Transformer flies: hold Jump), Titan Armor's G calls a dropship that slams the armour down for a timed build boost. Egg Hall (`EGGS`, south of the road, east of the leaderboard): four eggs bought with cash (Hazard $1K, Brick $10K, Steel $100K, Golden $1.5M) hatch pets (`PETS`, five per egg by rarity); equipped pets (3 slots, 5 with the pass) follow you and add their `bonus` to both the cash and gym multipliers; the Pet Merge machine turns 5 of the same pet into a Golden one (x2.5), 5 Golden into a Rainbow one (x6). Hatching passes (+3/+8/+16 eggs, Lucky Eggs, +2 Pet Slots) are cash passes in the Shop (`PET_PASSES`). Spin Wheel (`SPIN`, east of the Egg Hall): 3 free spins on a new save, +1 for every building you help finish, more bought with cash; prizes are cash (scaled by buildings finished), gym pads unlocked for good, the limited Mech pet and golden spins; a Mystery Jackpot every 40 spins (pity).

**Currency rule (root CLAUDE.md): nothing is ever bought with Gems/Robux.** Every shop item, pass, premium gym pad and instant-block boost costs in-game cash (`SHOP`, `GYM.tiers[].price`).

Three.js (vanilla, no React) + Vite + Rapier (`@dimforge/rapier3d-compat`, wasm inlined; `main.js` awaits its init at top level, hence `build.target: 'es2022'`). Everything is procedural (canvas textures); the only imported model is the Bloxity base rig `public/avatars/player.glb`. Font: Fredoka (loaded in `index.html`).

- `npm run dev` / `npm run build`. `VITE_DEV_MODE=true` (see `.env.example`) skips the Bloxity SDK/CDN. Deploy: `.github/workflows/deploy.yml` uploads `dist/` to Bloxity Hosting (main = prod, dev = dev channel).
- All tunables are in `src/config.js` (the rest of `src/` holds no theme values): identity, `SPAWN`, `PHYSICS`, the look (`TIME_OF_DAY` day/dusk/night, `LIGHT`, `GRAPHICS_PRESETS`, `BLOOM`, `NEON`), `CAMERA`, `SETTINGS`, the rig, and the game: `SAVE`, `DAYNIGHT`, `DESERT`, `COMPOUND`, `LAYOUT`, `TOWER`, `BUILDING_SCALE`, `BUILDINGS`, `ELEVATOR`, `STAIRS`, `STATS`, `UPGRADES`, `GYM`, `RANKS`, `SHOP`, `GIFT`, `DAILY`, `CREW`, `EVENTS`, `BOTS`, `AUDIO`, `JUICE`, `INTERACT`, `ROBOT_GEAR`, `ROBOT`, `RARITIES`, `PETS`, `EGGS`, `PET`, `PET_PASSES`, `SPIN`.
- All Bloxity SDK calls go through `src/bloxity.js` and must never throw (SDK may be blocked). It handles init/loading steps, auth (user/guest), settings (`graphics_quality`, `camera_sensitivity`, `show_fps`, `fullscreen`), avatar + proportion change events, the portal `respawn_request` event, the avatar customizer, and the matchmaker helpers the future net layer needs (`resolveServerEndpoint`, `locateRoom`, `updateRoom`).

## Files (`src/`)
- `main.js`: boot (Bloxity SDK -> renderer -> Rapier -> load save -> desert, site, pit, tower, elevator, stairs, cranes, fx, gym, leaderboard, bots -> player body -> `renderer.compileAsync` behind the loading screen -> avatar) and the per-frame game loop in `frame()` (wrapped in try/catch so an error never stops the loop): pit collecting, roof building, gym training, tower/rank/event reactions, guide arrow, HUD snapshot, autosave. `__game` (dev only) adds `state`, `tower`, `elevator`, `bots`, `gym`, `buildings(n)` (sets buildings finished and opens gym pads), `give({cash, strength, speed})`, `blocks(n)`, `view([x,y,z],[tx,ty,tz])` (free camera; `view(null)` releases it), `spins(n)`, `pet(id, tier)`, `reset()` (wipes the save).
- **Game state**: `stats.js` the saved progress (`state`), derived values (capacity, walk speed, grab/build rates, range, lift speed, muscle, rank, multipliers), mutations that emit events (`on`/`emit`), daily rewards, save/load (`SAVE.key`), number formatting. `cycles.js` the day/night clock (drives `lighting.setNight`) and world events (`stats.boosts`).
- **World**: `world.js` desert ground (dunes only outside the compound; inside is flat y = 0), mesas, oasis + palms, scattered rocks, clouds, `groundColliders()`. `site.js` the compound: pavers, roads, plaza, chain-link fence + entrance arch (fence colliders), lamps (5 real point lights, the rest just glow), trucks/containers/cabins/props, Upgrades and Shop kiosks; `blockMaterial()` is the shared stone block. `props.js` reusable prop builders (mixer truck, flatbed, forklift, container, cabin, cone, barrel, pallet, pipes, lamp, banner...). `pit.js` the Blocks pit (zone, stacks + colliders).
- **Tower**: `shapes.js` footprints (chamfer, blob, hex, round, cross, star), polygon offset/point tests, per-floor geometry (slab + glass with perimeter-mapped window UVs), roof cap/edge, Rapier trimesh prisms. `tower.js` the shared building: `buildingSpec(n)`, instanced floors, roof blocks popping in (fill order from the elevator exit), the build front (`nearestFront`), floor/building completion, crown, sinking + next building, colliders (prism + parapet with gaps at the exits), `anchors` (elevator/stairs placement), events `floor`/`complete`/`building`/`height`. `elevator.js` lattice masts + your cage (stand inside to ride; it re-arms once you step out) + the crew cage loop, gates and the roof bridge. `stairs.js` the switchback stair tower, rebuilt to the roof height on every `height` event. `cranes.js` two animated tower cranes that grow with the building. `lobby.js` the finished building's lobby (`INSIDE`, `BUILDINGS[].lobby` per-building look): for `INSIDE.time` after completion the two lowest floors are a tall glass hall (tower.js cuts the doorway out of the glass and swaps the colliders: floor plate, walls with a door gap, ceiling, crown cylinder), furnished and baked here (lounges, palms, columns, chandeliers, core); standing inside pays 5X Strength + Speed (main.js `insideReward`), the HUD bar shows `5X INSIDE m:ss`, bots wander in, and the core's express elevator (E) swaps you behind closed doors to an identical cab in a hut on the roof (and back).
- **People**: `characters.js` worker outfit on any rig (vest, hard hat, backpack frame that fills with blocks), `setMuscle` (torso/arm bulk, inverse scale on the offset bones), rank name tags, bot bodies. `bots.js` the worker bots' state machine (pit -> crew cage -> roof -> back, gym visits), their stats for the leaderboard, `near()` for the crew prompt, `evict()` when you take their machine. `gym.js` the gym: walkway + entrance arch, one themed pad per tier (`GYM.tiers[].theme` -> `GYM.themes`: painted floor, decor, ambient particles; premium pads raised with steps), a bench press + treadmill each, stations with `lie`/`stand` poses, a force field + padlock over locked pads (`refresh(buildings, owned, celebrate)` drops it with a burst on the `buildings` / `gymOwned` events), live machine effects for any occupant (belt, console screen, underglow, plate rings, floor aura, run trails) and `rep(st, mine)` bursts. `gymKit.js` the models: `buildBench` / `buildTreadmill` (static parts painted per vertex on shared `finish` materials so the bake merges the whole gym; the bar, belt, LEDs and screen stay live), `buildLock`, and `DECOR[theme]` (corner/back-of-pad props, colliders, emitters and per-frame anims). The animator has a `bench` activity (inputs `activity`, `rep`). `dressWorker` records the avatar's bind pose (`root.userData.restPose`) so gear can attach to an animated avatar.
- **Robot Gear**: `gear.js` the models: `wearGear(root, id)` armour on the bones (built in rig units against the bind pose; holder + inner group per part so the suit-up flies them in; hides the vest / hard hat under a suit / helmet), `makeVehicle` (mixer, big rig, jet), `makeDropship`, `makePod`. `robotGear.js` the hall (floor, walls, arch, pedestals with display mannequins, vehicles, cards repainted on `gear` events). `robotPlayer.js` the player side: pedestal prompts (buy / wear / take off), suit-up beam + clanks + power chord, G ability (transform, jet flight via `player.fly`, Titan dropship + `boosts.gearBuild`), engine loops, the G key hint and the touch gear button. Gear stats live in `stats.js` (`state.gear`, `gearOn`, `gearBlocks`, `gearBuild`, `buyGear`, `wearGear`); main.js multiplies the build loop by `gearBlocks()` and walk speed by `robots.speedMul()`.
- **Pets + eggs**: `eggs.js` the Egg Hall (gable roof with colliders so the chase camera stays under it, carpet, pedestals + lathe eggs with painted shells, the Pet Merge machine; `eggs[].front` is where you stand for its panel, `wobble(id)`). `pets.js` `makePetMesh(def, tier)` (blocky model per `kind`, baked; Golden = gold metal, Rainbow = hue-cycling neon) and `createPetFollowers` (fanned out behind you, hop while moving). `petArt.js` SVG portraits (`petSvg`, black silhouettes for pets not hatched yet), `eggSvg`, `boostText`, `petTitle`. `petUi.js`/`petUi.css` the egg panel (tiles with odds, Hatch E / Multi F / Auto T, pass buttons that open the Shop on that pass), the hatch show, the Pets window (equip / delete / Equip Best) and the Pet Merge window. Pet state in `stats.js` (`state.pets` [{uid, id, tier}], `petEq`, `petSeen`, `addPet`, `equipPet`, `mergePets`, `rollEgg`, `petBonus` which feeds `cashMultiplier`/`gymMultiplier`).
- **Spin wheel**: `spin.js` the 3D stage (painted wheel, marquee bulbs, `spinTo(index)` replays the window's spin, `repaint(slices)`), `spinPrizes.js` labels / roll / payouts / Mystery Jackpot, `spinUi.js`/`spinUi.css` the window (pity meter, wheel whose hub spins, Normal / Golden toggles, cash spin packs). A spin-won gym pad sets `state.gymOwned[tier]`, which `gym.tierUnlocked` honours for any tier. `state.spins` = { normal, golden, pity }.
- **UI**: `hud.js`/`hud.css` (progress bar + cash block boosts, event, stats, rank card, menu buttons, status card, banners, pops, gym LIFT button, ride bar; keeps clear of Boxity's reserved corner via `setReserved`), `hudIcons.js` SVG icons, `windows.js`/`windows.css` (Shop, Upgrades, Ranks, Daily, gift reveal) on the shared `uiWindow.js` shell, `juice.js` DOM bursts, `interact.js`/`interact.css` proximity prompts (E / tap the pill), `leaderboard.js` the in-world boards and podium.
- **Effects + audio**: `fx.js` pooled 3D effects (sparks, dust, confetti, flying blocks, rings, fireworks), `particles.js` looping GPU emitters (sand, pit, premium pads, roof). `audio/` synthesised sound: `core.js`, `synth.js`, `sfx.js` (UI/reward one-shots), `game.js` (blocks, hoist, gym, floor/building fanfares), `robot.js` (servo, armour lock-in, power up/down, transform ratchet, dropship, slam, and the diesel / jet / thruster / rotor loops on the engine bus), `index.js` (install, button clicks, jump/land, ducking).
- **Player**: `player.js` kinematic capsule + Rapier `KinematicCharacterController`; walk speed comes from `player.walkSpeed`, and `player.locked` + `player.hold` pin the feet (elevator ride, gym machine). `camera.js` third-person chase cam / first person, `modes.js`, `input.js`, `touch.js` + `touch.css`. `avatar/` rig, loader, animator.
- **Sky and light**: `lighting.js` sky shader, stars, PMREM environment, shadowed sun following the player, fog, a day -> dusk -> night blend (`setNight(0..1)`, `onNightChange`, `getLampFactor`). `postfx.js` bloom (High/Ultra only).
- **Materials and textures**: `textures.js` canvas painters (dune sand, asphalt, pavers, concrete, blocks, curtain-wall windows with a night emissive map, steel lattice, strata, hazard stripes, corrugated metal, outlined text, ...). `propkit.js` `std`, `glow`, `neon`, `put`, `box`, `cyl`, `solidBox`/`solidPole`/`solidFootprint`, `label` (sprite) and `flatText` (decal). `bake.js` merges static props into one mesh per material.
- Controls: WASD/arrows, Shift sprint, Space jump (on a gym machine: an extra rep), E use / leave a machine, mouse look (click grabs the cursor = pointer lock; Esc closes a window, else releases it, then opens the portal menu), wheel zoom, V mode, N skip time of day, M mute, R respawn, next to an egg E hatch / F multi hatch / T auto hatch (touch: the egg panel's buttons), G Robot Gear ability (touch: the gear button in the thumb arc; hold Jump to fly as a jet). Never bind P (CrazyGames: Boxity's pause menu).
- Graphics: `graphicsPreset(name)` in config resolves the preset; on coarse pointers the default is Medium and every preset is capped by `MOBILE_GRAPHICS_CAP` (DPR 1.5, 1024 shadow map, no bloom), because the Bloxity SDK sends `High` itself.
- Boxity layout (required to publish, docs.bloxity.io Platform UI rules): Boxity draws the menu / pause menu, chat, emotes, avatar editor, invite, leaderboard and sign-in itself in a toolbar in the top-left corner with the chat feed under it, so the game never draws those buttons and keeps any HUD out of those rectangles (`bloxity.onReservedAreas`).

## Mobile & responsive (required for every change)
The game must play on phones and tablets (portrait and landscape) as well as desktop. Treat a feature as unfinished until it works on touch and on a small screen.
- **Input**: every action needs a touch path, not just a key. Use Pointer Events (`pointerdown/move/up`, check `e.pointerType`), never mouse-only events. Layout (implemented in `src/touch.js`): left-thumb virtual joystick -> `inputState.move`, right-side drag -> `inputState.look`, on-screen buttons for jump/sprint/mode/etc., pinch -> `inputState.zoom`. Everything still feeds `inputState` in `src/input.js` so game code stays input-agnostic. Pointer lock does not exist on touch; never rely on it.
- **Detection**: decide touch UI with `matchMedia('(pointer: coarse)')` / `navigator.maxTouchPoints`, not the user agent. Show touch controls only on coarse pointers; a device can have both.
- **Layout/UI**: HUD and menus use relative units (`%`, `vw/vh`, `dvh`, `clamp()`) and flexbox/grid, no fixed pixel layouts. Tap targets >= 44px. Respect notches with `env(safe-area-inset-*)` (viewport already has `viewport-fit=cover`). Text readable at 360px width. No hover-only interactions. Add `touch-action: none` on the canvas and game controls so the browser does not scroll/zoom.
- **Resize/orientation**: anything sized to the screen (camera aspect, renderer, HUD) must react to `resize` (covers orientation changes). Use `visualViewport` where the on-screen keyboard or browser bars matter.
- **Performance**: mobile GPUs are weak. Respect the `graphics_quality` presets in `src/config.js` (cap DPR, shadow map size, draw distance); default to a lower preset on coarse-pointer devices. Avoid per-frame allocations; keep draw calls and texture sizes low.
- **Testing**: check every UI/input change at a phone viewport (e.g. 375x812 and landscape 812x375) with touch emulation, plus desktop, before calling it done.
